Select 구성요소 ★ 배치 방식은 sample 파일 확인 ★

1. 아이콘 (icon)
잠금 lock / 왕관 crown
	-특이사항-
	스테이지 클리어 상황에 맞게 배치

2. 스테이지 (stage) [N - Normal] [HL - HightLighted] [Locked]
피라미드 / 성채 / 한옥 (이름 추후 조정 가능성)

	-특이사항-
	(1) 일반(N) - 클리어 하지 않은 플레이 가능한 스테이지

	(2) 잠금(Locked) - 스테이지 해금 조건을 달성하지 않은 스테이지
	<흑백 배경, 회색 폰트>  <잠금 아이콘 lock 및 해금조건 표기>
	스테이지 해금 조건은 추후 논의

	(3) 클리어 (Completed) - 해당 스테이지 내에 모든 유물을 획득한 스테이지
	<금색 폰트색> <유물 개수 위에 왕관 아이콘 crown>

	(4) 선택 (HightLighted) - 선택된 스테이지
	<흰 테두리 표기><기본 이미지보다 살짝 커야함>

2. 버튼 (btn) [N - Normal] [HL - HightLighted]
뒤로가기{공용} (back) / 새로시작 (newgame) / 이어하기 (loadgame)

	-특이사항-
	버튼 선택시 <H> 사용
	5/6 기준, 기존 버튼 하이라이팅 방식과 다른 방식 적용
	문제 발생시 말씀주세요
